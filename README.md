# IPI Static Demo

Static demonstration site for **IPI — Institut Pembelajaran Indonesia**, published with GitHub Pages.

This repository is generated from the private full-stack project `ishak21/ipi-website`. GitHub Pages serves the visual demo only: landing page, responsive layout, event empty state, SEO files, and login mockup. Full-stack features such as MySQL, OAuth/local authentication, CMS editing, uploads, event registration, and reminders remain in the private application repository and require Node.js hosting.

Live site: https://ishak21.github.io/
